# Falcon-1024 known-answer test vectors

`falcon1024_det_kat.json` holds authentic Falcon-1024 **deterministic
(det1024)** known-answer test triples — `(public_key, message, signature)` —
used to validate `avm_proofpack.consensus.falcon.falcon1024_verify`.

## Why det1024

go-algorand signs and verifies Falcon in **deterministic, compressed** form
via its cgo binding to the Falcon C reference
(<https://github.com/algorand/falcon>). det1024 replaces the random 40-byte
salt with a fixed, versioned salt and uses header byte `0xba` (`0x3a | 0x80`).
This is the format that appears in Algorand/Voi state proofs, so it is the
format these vectors and the verifier target. The verifier also accepts the
standard salted compressed format (header `0x3a`), which shares the same core.

## Provenance (how the vectors were produced)

The triples were generated by compiling the **exact** go-algorand Falcon C
reference (`github.com/algorand/falcon`, branch `main`: `deterministic.c`,
`falcon.c`, `codec.c`, `common.c`, `vrfy.c`, `sign.c`, `keygen.c`, `fft.c`,
`fpr.c`, `rng.c`, `shake.c`) with a small driver that, for each index `i`:

1. derives the message as `SHAKE256("msg-%04d" % i)` read for `i` bytes,
2. derives a keypair from the seeded PRNG `shake256_init_prng_from_seed("key-%04d" % i)`,
3. signs with `falcon_det1024_sign_compressed`,
4. self-checks with `falcon_det1024_verify_compressed`.

This mirrors `TestKATs` / `testKAT` in the reference's `falcon_test.go`.

**Authenticity check.** Each generated signature was asserted **byte-identical**
to `FALCON_DET1024_KAT[i]`, the official vector array vendored in the same
reference's `tests/test_deterministic_kat.h`. Because the signature matches the
official KAT bit-for-bit, the corresponding public key and message (produced by
the same official code from the documented seeds) are authentic as well.

Indices vendored here: 0 (empty message), 1, 33, 128, 500.

## Parameters confirmed while producing these vectors

- `n = 1024`, `q = 12289`.
- Squared l2-norm acceptance bound `beta^2 = 70265242` (`l2bound[10]` in the
  C reference `common.c`). Note `34034726` is the **Falcon-512** bound.
- Public key: header `0x0a` (`0x00 | logn`) + 1792 bytes of 14-bit
  coefficients (`modq_decode`).
- Signature: header `0xba`, salt-version byte, then Golomb-compressed `s2`
  (`comp_decode`).

The generator, C sources, and the byte-for-byte cross-check are not vendored
(they require a C toolchain); only the resulting offline vectors are, so the
test suite stays pure-stdlib.
